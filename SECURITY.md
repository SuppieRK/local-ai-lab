# Security Policy

This is a personal home lab repository.

If you discover a security issue:

1. Do not publish it immediately.
2. Open a private issue if possible or reach out directly.
3. Provide clear reproduction steps.

## Scope

- Vulnerabilities in scripts or configurations are included here.
- Obviously dangerous defaults (if any slip in).
- Any situation where this repository accidentally operates as an OpenClaw-style VaaS (Vulnerability-as-a-Service).

## Not in Scope

- The security of your network.
- The security of your router.
- The security posture of AI agents that think prompt injection is a feature.
- The security of your future forest-based remote role.

Run things responsibly.  
Do not expose experimental services to the internet unless you fully understand the consequences.

If your lab turns into an unintended public demo of "autonomous remote code execution," that's on you.

At least don't blame the README.
