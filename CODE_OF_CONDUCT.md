# Code of Conduct

Be reasonable.

That's it.

## Expected Behavior

- Assume good intent.
- Criticize code, not people.
- Prefer calm technical arguments over emotional ones.
- Do not turn discussions into product pitches.

## Not Welcome

- Personal attacks.
- Elitism about hardware.
- Evangelism of any kind.

We are here to build practical things, not identities.

If something feels unnecessary, it probably is.
